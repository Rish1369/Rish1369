## 🚀 Featured Projects

### 1. [RevRecover-AI](https://github.com/Rish1369/RevRecover-AI): Revenue Recovery Agent
A full-stack fintech solution that automates **dunning**, the process of recovering failed or overdue payments, for merchants.

- **Problem:** Failed payments quietly cost subscription and billing businesses revenue, and chasing them by hand is slow and inconsistent.
- **Solution:** An agent-driven platform that takes over the recovery process end to end, so merchants recover more revenue with far less manual follow-up.
- **How it works:**
  - Detects failed or overdue payments
  - Runs an automated recovery workflow (reminders, retries and follow-ups)
  - Gives merchants visibility into what has been recovered and what is still pending
- **Stack:** Python, FastAPI (robust backend), full-stack web interface
- **What it shows:** Backend API design, workflow automation and building for a real business problem in fintech

### 2. [Code-Sense](https://github.com/Rish1369/Code-Sense): Chat With Any Codebase
A production-ready developer assistant that lets you ask questions about any GitHub repository in plain English.

- **Problem:** Understanding an unfamiliar codebase takes hours of reading files and tracing logic.
- **Solution:** Paste a GitHub repository URL, let the agent index the code, then chat with it. Answers are grounded in the actual code rather than guesswork.
- **How it works:**
  1. **Ingest:** Paste a repository URL
  2. **Index:** The agent processes the codebase so it can be searched
  3. **Retrieve:** Your question pulls the most relevant code sections
  4. **Answer:** A natural-language response based on those sections
- **Use cases:** Onboarding to a new project, understanding how a feature works, reviewing open-source code before contributing
- **Stack:** Python
- **What it shows:** Retrieval-based (RAG-style) AI application design, working with real repositories and building developer tooling
